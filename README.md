## 📄 O que é

Um site pessoal que funciona como currículo. Ele reúne quem eu sou, como falar comigo, onde estudei, as tecnologias que uso e os projetos que já fiz. Tudo em **HTML, CSS e JavaScript puro**, sem framework e sem etapa de build.

## ✨ Funcionalidades

- **Tema claro e escuro.** Na primeira visita o site segue o tema do sistema. Depois que você escolhe um, a preferência fica salva no navegador.
- **Responsivo.** No celular, o menu vira um painel lateral que fecha com o `Esc`, com um clique fora ou ao escolher uma seção.
- **Projetos carregados de um JSON.** Os cards da seção de projetos são montados a partir do `data.json`. Para adicionar um projeto novo, basta incluir um item no arquivo.
- **Acessível.** Tem link para pular direto ao conteúdo, botões com `aria-label` e imagens com carregamento preguiçoso (`loading="lazy"`).
